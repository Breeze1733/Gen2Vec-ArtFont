# 算法原理说明

本文档说明系统的关键算法原理与实现依据，覆盖赛题要求的五个环节：**图像预处理、轮廓提取、颜色分层、路径拟合与回渲染对比**。

对应源码：

| 模块 | 源码 |
| --- | --- |
| 图像预处理 | `services/vectorizer-api/app/image_processing.py` |
| 矢量化引擎与质量评估 | `services/vectorizer-api/app/vectorization.py` |
| 文生图提示词合成与工作流路由 | `services/txt2img-api/app/generator.py` |

---

## 一、总体流水线

| 阶段 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 1. 文生图 | 文字 + 风格提示词 | 文本分析 → 工作流路由 → 提示词合成 → ComfyUI 采样 | 原始位图 |
| 2. 背景分离 | 原始位图 | 显著性检测 + Alpha 抠图 | 透明 PNG |
| 3. 预处理 | 透明 PNG | 白底滤除 → 保边去噪 → 颜色量化 → 裁剪 → 抗锯齿 | 分层离散的前景位图 |
| 4. 矢量化 | 前景位图 | 形态学 → 连通域滤波 → 路径拟合 → 图层分类 | SVG |
| 5. 质量评估 | 原图 + SVG 回渲染图 | SSIM / 边缘相关 / 色彩直方图相关 | 保真度得分 |

## 二、图像预处理

### 2.1 显著性目标检测与深度背景分离

使用深度显著目标检测模型 **ISNet-General-Use**（Interconnected Saliency Network，U²-Net 系结构）。输入归一化位图 $I \in \mathbb{R}^{3 \times H \times W}$，通过多尺度残差 U 形结构（ReSQU）聚合高层语义与底层边缘特征，输出逐像素前景置信度掩模：

$$S(x, y) = \sigma\left(f_\theta(I(x, y))\right) \in [0, 1]$$

对未定过渡区域 $\Omega_{\text{unknown}}$，在图像合成约束方程下求解最优透明度通道：

$$I(x, y) = \alpha(x, y) F(x, y) + \left(1 - \alpha(x, y)\right) B(x, y)$$

其中 $F$、$B$ 为前景与背景颜色的局部先验。该步骤消除半透明羽化光晕，同时保留笔画内部实心像素。

**为什么不用简单阈值抠图**：艺术字的描边、渐变、阴影会让前景与背景在亮度上重叠，固定阈值会同时切掉笔画边缘和保留背景残留。

### 2.2 边缘连通域分析与纯白溢出底衬滤除

部分生成结果带有非透明的纯白底衬。算法映射至 HSV 感知色彩空间，提取近纯白区域：

$$M_{\text{white}}(x, y) = \left[V(x, y) \geq V_{\text{thresh}}\right] \wedge \left[S(x, y) \leq S_{\text{thresh}}\right]$$

随后做 8-邻域连通分量标记，遍历图像四边缘取并集：

$$L_{\text{border}} = L_{\text{top}} \cup L_{\text{bottom}} \cup L_{\text{left}} \cup L_{\text{right}}$$

**只有与画布外围连通的白色区域**才被置为完全透明。这样避免把字体内部的白色镂空（如「口」「日」的封闭区域）误删。

阈值由 `white_value_threshold`（默认 245）与 `white_saturation_threshold`（默认 20）控制，可用 `remove_edge_white_background` 关闭。

### 2.3 双边保边滤波去噪

扩散模型输出常带颗粒伪影，但高斯滤波会模糊笔画边缘。本模块采用非线性双边滤波，在**空间欧氏距离**与**色彩辐射距离**的双重高斯核联合约束下平滑：

$$I_{\text{filtered}}(p) = \frac{1}{W_p} \sum_{q \in \Omega} I(q) \cdot g_s(\lVert p - q \rVert) \cdot f_r(\lVert I(p) - I(q) \rVert)$$

其中空间核 $g_s(\lVert p - q \rVert) = \exp\left(-\lVert p - q \rVert^2 / 2\sigma_s^2\right)$，色彩核 $f_r(\lVert I(p) - I(q) \rVert) = \exp\left(-\lVert I(p) - I(q) \rVert^2 / 2\sigma_r^2\right)$，归一化因子 $W_p = \sum_q g_s \cdot f_r$。

色彩核使滤波权重随色差衰减，因此**跨边缘的像素不参与平均**——伪影被压制而笔画梯度阶跃保持锐利。

### 2.4 CIELAB 感知色彩空间 K-Means++ 颜色量化

RGB 空间的欧氏距离与人眼主观色差严重非线性，直接聚类会把视觉上明显不同的颜色并成一类。算法先将前景像素转换到 CIELAB 空间 $(L^*, a^*, b^*)$，使欧氏距离正比于感知色差：

$$\Delta E^*_{ab} = \sqrt{(\Delta L^*)^2 + (\Delta a^*)^2 + (\Delta b^*)^2}$$

取不透明前景点集 $X = \{x_i \in \mathbb{R}^3 \mid \alpha_i > \alpha_{\text{threshold}}\}$，用 **K-Means++** 初始化 $k$ 个质心，迭代最小化组内离差平方和：

$$J = \sum_{j=1}^{k} \sum_{x \in S_j} \lVert x - \mu_j \rVert^2, \quad S_j = \left\{x \in X \;\middle|\; \arg\min_m \lVert x - \mu_m \rVert = j\right\}$$

聚类数 $k$ 由 `color_precision` 决定。像素赋值为最近质心颜色后重映射回 sRGB，**Alpha 通道原样保留**。

**收益**：渐变产生的成千上万种中间色被收敛为有限主色，显著减少矢量化输出的碎块路径数量，是「颜色分层」质量的前提。

### 2.5 紧致外接矩形裁剪与亚像素抗锯齿

提取 $\alpha > \alpha_{\min}$ 的前景几何包围盒：

$$\text{AABB} = \left[\max(0, x_{\min} - \delta),\ \max(0, y_{\min} - \delta),\ \min(W, x_{\max} + \delta),\ \min(H, y_{\max} + \delta)\right]$$

裁剪无用留白以收敛视口、提升后续轮廓拟合效率。随后施加亚像素高斯软化 $\alpha_{\text{soft}} = G_\sigma * \alpha$，消除光栅离散采样造成的阶梯锯齿。

## 三、轮廓提取与路径拟合

### 3.1 二值掩模的形态学与连通域面积滤波

| 运算 | 公式 | 作用 |
| --- | --- | --- |
| 闭运算 | $A \bullet B = (A \oplus B) \ominus B$ | 填补笔画内部微孔 |
| 开运算 | $A \circ B = (A \ominus B) \oplus B$ | 滤除轮廓毛刺与游离噪点 |

随后做 8-邻域连通域标记，按**动态面积阈值**过滤孤立飞溅：

$$S_{\min} = \max\left(2, \frac{W \times H}{D_{\min}}\right)$$

$D_{\min}$ 由 `min_area_divisor` 控制，随预设变化（`clean` 1500 → `ultra` 24000）。面积低于阈值的连通块被判定为噪点丢弃，保证轮廓紧凑连续。

### 3.2 三次贝塞尔样条路径拟合

轮廓点列拟合为三次贝塞尔曲线：

$$B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3, \quad t \in [0, 1]$$

其中 $P_0, P_3$ 为锚点，$P_1, P_2$ 为方向控制点。

**锚点划分准则**：按曲率特征点自适应分段。通过 `corner_threshold` 判定转折硬角——设相邻段方向向量 $v_1, v_2$：

$$\cos\theta = \frac{v_1 \cdot v_2}{\lVert v_1 \rVert \, \lVert v_2 \rVert}$$

夹角变化超过阈值时保留为硬锚点（尖角），否则在连续导数约束下拟合平滑样条。这样既保住书法笔锋的锐角，又让圆弧部分保持平滑。

`length_threshold` 控制参与拟合的最小线段长度，值越小保留细节越多。

### 3.3 语义化图层解耦与拓扑分类

矢量化后需把扁平的路径集合重组为**可编辑的语义图层**。算法对每条闭合路径 $p$ 计算四个特征：

| 特征 | 定义 |
| --- | --- |
| 归一化中心距离 | $d_{\text{center}}(p) = \dfrac{\sqrt{(c_x - C_x)^2 + (c_y - C_y)^2}}{R_{\text{diag}}}$ |
| 相对面积比 | $a_{\text{rel}}(p) = \dfrac{w_p \times h_p}{W \times H}$ |
| 感知亮度 | $Y(p) = 0.299R + 0.587G + 0.114B$ |
| 饱和度 | $S(p) = \dfrac{\max(R,G,B) - \min(R,G,B)}{\max(1, \max(R,G,B))}$ |

其中画布中心 $(C_x, C_y) = (W/2, H/2)$，对角线半长 $R_{\text{diag}} = \sqrt{(W/2)^2 + (H/2)^2}$。

**四层拓扑分类规则**：

| 图层 | 判定条件 | 典型内容 |
| --- | --- | --- |
| `layer-shadow` 投影阴影 | $(Y < 0.22 \lor V < 0.25) \wedge a_{\text{rel}} < 0.70$，或暗调底衬 $(Y < 0.35 \wedge S < 0.25 \wedge c_y > C_y \wedge a_{\text{rel}} < 0.50)$ | 投影、暗色底衬 |
| `layer-decorations` 装饰图形 | $d_{\text{center}} > 0.35 \wedge a_{\text{rel}} < 0.10$ | 外围花瓣、叶片、光芒 |
| `layer-stroke` 描边轮廓 | 底衬闭合大轮廓（`index = 0` 且 $a_{\text{rel}} > 0.20$）或高反差金边 | 描边、外框 |
| `layer-main-text` 主体文字 | 其余核心字形实体填充 | 主结构笔画 |

分类结果写入 SVG 的 `<g>` 分组与 `inkscape:groupmode`，使评审可在矢量软件中按图层单独调整颜色或拆分。

## 四、回渲染对比与保真度评估

为避免「只输出 SVG 却无法判断质量」，系统引入**回渲染闭环**：将生成的 SVG 用 `resvg_py` 渲染回 PNG，与预处理后的透明 PNG 对比。

综合空间结构、边缘梯度与感知色彩三维指标，保真度得分 $\text{Fidelity} \in [0, 100]$：

$$\text{Fidelity} = 0.50 \times \text{SSIM}(I_{\text{orig}}, I_{\text{vec}}) + 0.30 \times \text{Corr}(\nabla I_{\text{orig}}, \nabla I_{\text{vec}}) + 0.20 \times \text{Corr}(\text{Hist}_{\text{Lab}}^{\text{orig}}, \text{Hist}_{\text{Lab}}^{\text{vec}})$$

| 分量 | 权重 | 含义 |
| --- | :---: | --- |
| SSIM | 0.50 | 结构相似度，11×11 局部窗口，衡量整体结构还原 |
| $\text{Corr}(\nabla I)$ | 0.30 | Sobel 边缘响应的皮尔逊相关系数，衡量轮廓是否对齐 |
| $\text{Corr}(\text{Hist}_{\text{Lab}})$ | 0.20 | CIELAB 直方图相关系数，衡量配色是否保真 |

该得分写入 `metadata.json` 的 `quality.svg_fidelity`，作为赛题「矢量还原度」验收项的量化依据。可用 `evaluate_quality: false` 关闭以节省时间。

## 六、文生图侧的关键算法

### 6.1 文本分析

`_analyze_text` 把输入拆为汉字、拉丁字母、数字三类字符运行段，并统计残余符号与空白。**只统计汉字与拉丁字母**参与语种判定，数字、标点、符号、空白一律不计入分母。

因此 `冰川 100%` 归为纯中文；无字母输入（纯数字/符号/空）并入英文链。

**为什么这样做**：早期实现要求汉字占比 ≥ 50% 才算中文，而分母包含数字与标点，导致 `咖啡 Latte 2.0` 这类混排文本被误判为英文并送进 Flux（Flux 渲染汉字质量差，会出现缺笔断笔）。

### 6.2 三路工作流路由

`_classify_text` 输出 `chinese` / `english` / `mixed` 三态，据此选择候选工作流：

| 文本类型 | 优先级 1 | 优先级 2 | 兜底 |
| --- | --- | --- | --- |
| 纯中文 | `qwen_image_2512_gguf` | `test_z_image_turbo` | Pillow stub |
| 纯英文 | `flux_schnell` | `test_z_image_turbo` | Pillow stub |
| 中英混排 | `test_z_image_turbo` | — | Pillow stub |

提示词模板无需切换——`_detect_workflow_model` 会从工作流节点反推模型族（如从节点推断 lumina2），混排文本落入 z-image 工作流后自动套用中文模板。

### 6.3 提示词合成

提示词按固定区块顺序拼装：

```
background → style → layout → content → accuracy → inversion
```

| 区块 | 内容 |
| --- | --- |
| `background` | 背景与留白约束 |
| `style` | 用户风格描述 |
| `layout` | 版式意图（横排 / 竖排 / 弧形等，由 `_detect_layout_intent` 判定） |
| `content` | 要渲染的文字内容 |
| `accuracy` | 字形准确性约束（防缺字、错字、笔画断裂） |
| `inversion` | 负面提示词映射 |

渲染规则由 `RenderProfile` 承载，按模型族（Flux / Z-Image）分别定义，保证同一套用户输入在不同模型下都能得到适配的提示词。

合成结果写入 `metadata.json` 的 `prompt_synthesis` 块，其中 `positive_prompt` 与实际注入工作流的提示词**逐字节一致**，可据此完全复现生成过程。
