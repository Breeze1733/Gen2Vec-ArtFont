# 用户使用说明

本文档面向**使用本应用的用户**，说明桌面端与 CLI 两种入口的使用方法。

- **桌面端**：图形界面，适合日常使用。
- **CLI**：命令行工具，适合批量处理与自动化验收。

两者共用同一套后端服务与产物目录，可以混用、互查。

---

## 一、桌面端

## 1. 启动

安装完成后，从开始菜单或安装目录启动「矢量艺术字生成器」。

首次启动会进入引导流程，依次检查推理引擎、AI 模型并启动后端服务。如果引擎或模型缺失，会弹窗询问是否下载——选择「开始下载」即可，下载脚本会自动跳过已存在的文件。

启动过程中会显示进度。完成后进入主界面。

## 2. 界面结构

界面顶部有三个标签页：

| 标签页 | 用途 |
| --- | --- |
| **输入** | 填写参数并触发生成 |
| **输出** | 查看本次生成的结果与预览 |
| **历史** | 浏览、恢复、删除历史任务 |

## 3. 三种工作模式

在「输入」页左侧选择模式。

### 3.1 单条生成

输入一条文本，生成对应的艺术字位图并矢量化。

| 字段 | 说明 |
| --- | --- |
| 文字内容 | 艺术字文本，建议 2–8 个字符，示例：`霓虹之风` |
| 风格提示词 | 描述期望的艺术风格，示例：`霓虹渐变、金属质感` |
| 负面提示词 | 需要避免的元素；留空时由后端追加内置负面提示词，输入框显示常用提示：`缺字，错字，笔画断裂，杂乱背景，低清晰度` |
| 分辨率 | 从预设尺寸中选择，或选「自定义」手动输入，示例：`1400x800` |
| 随机种子 | 固定种子可复现同一结果；留空或为 0 时随机 |

### 3.2 批量生成

一次处理多条文本，逐条生成并写入批量汇总表。

批量输入框每行一条，字段用 `|` 分隔：

```text
文本 | 风格提示词 | 负面提示词(可选) | 种子(可选)
```

示例：

```text
霓虹之风 | cyberpunk neon glow | 模糊,低质量
七里香 | 清新国风、墨绿色金边
夏日冰饮 50% | 清爽蓝白配色 | | 42
```

批量模式下另有「全局负面提示词」「分辨率」「随机种子」三个字段，应用于所有条目。

处理过程中会显示进度条与逐条状态；单条失败不会中断整批，失败原因会记录在该条目上。

### 3.3 图片矢量化

跳过文生图，直接把已有的 PNG / JPG 图片转换为 SVG。

选择本地图片文件后，其余参数与单条生成一致（共用同一套矢量化参数）。

## 4. 矢量化参数

「输入」页右侧为矢量化参数面板，适用于全部三种模式。

### 预设

| 预设 | 适用场景 |
| --- | --- |
| 清爽 | 色块分明、结构简单的图，输出体积小 |
| 平衡 | 默认值，兼顾质量与体积 |
| 精细 | 细节丰富、需要保留较多层次 |
| 超清 | 追求最高还原度，输出体积最大 |

选择预设会自动填入下方六个参数，之后可以手动微调。

**手动调整任一参数后，四个预设按钮的选中高亮会全部消失**，表示当前参数已不等同于任何预设；重新点击某个预设即可恢复高亮并覆盖为预设值。

### 参数

| 参数 | 取值范围 | 说明 |
| --- | --- | --- |
| 颜色精度 | 1–8 | 颜色聚类的精度，值越高保留的颜色层次越多 |
| 斑点过滤 | 0–64 | 过滤面积小于阈值的小色块，值越高去除的小色块越多 |
| 拐角阈值 | 1–180 | 判定拐角的阈值，值越低越容易识别尖角 |
| 长度阈值 | 1–64 | 拟合曲线的最小长度，值越低保留的细节越多 |
| 图层差异 | 1–64 | 图层间的颜色差异阈值 |
| 放大倍数 | 1–4 | 矢量化前的放大倍数，可提升边缘平滑度 |

调整完成后点击「开始生成」。

## 5. 结果面板

生成完成后自动切换到「输出」页。

- **预览区**：并排显示原图、透明背景图、SVG 回渲染预览图
- **指标区**：显示耗时、图片透明度、SVG 还原度等元数据
- **操作**：可打开输出目录、打开 SVG 预览

批量模式下会列出全部条目及其状态，点击某一条可查看该条的详细结果与元数据。

生成失败时，界面会清空输出并自动退回「输入」页，顶部横幅显示失败原因。

## 6. 历史任务

「历史」页列出历史记录。每条记录保存了任务目录路径，可以：

- 恢复任务：重新读取该任务的产物并展示
- 删除任务：移除历史记录

历史记录只保存路径与参数，实际产物在输出目录中。

## 7. 输出位置

产物默认输出到**安装目录下的 `outputs/`**：

```text
<安装目录>/
├─ 矢量艺术字生成器.exe
├─ gen2vec_cli.exe
└─ outputs/
   ├─ task_YYYYMMDD_HHMMSS_mmm_<文本>_seed-<种子>/
   └─ batch_summary.csv
```

也可以设置环境变量 `ART_TEXT_OUTPUT_ROOT` 指定其他输出根目录。

每次任务生成独立目录，包含：

| 文件 | 说明 |
| --- | --- |
| `original.png` | 文生图原始位图，或用户上传的原图 |
| `transparent.png` | 透明背景 PNG |
| `result.svg` | SVG 矢量图 |
| `preview.png` | SVG 回渲染预览图 |
| `metadata.json` | 参数、耗时、质量指标等元数据 |
| `run.log` | 运行日志 |
| `workflows/` | 文生图任务的工作流快照（`workflow_api.json`、`nodes.md`、`model_dependencies.json`） |

## 二、CLI 命令行

## 1. 定位

CLI（`gen2vec_cli.exe`）是**随桌面端安装包交付的自动化验收控制台**，不独立分发。

- **日常使用** → 启动桌面端图形界面
- **批量测试 / 脚本自动化 / 评审验收** → 使用 CLI

CLI **不负责启动后端**：使用前需由桌面端（或手动）启动后端。`shutdown` 命令仅用于主动关闭已运行的后端。

## 2. 运行方式

### 方式 1：安装包自带

安装桌面端后，在安装目录下运行：

```powershell
cd "$env:LOCALAPPDATA\Programs\矢量艺术字生成器"
.\gen2vec_cli.exe <command> [options]
```

若安装时选择了「为所有用户安装」或自定义目录，请替换为实际安装路径。此时桌面端已在后台启动后端，CLI 可直接执行。

### 方式 2：源码直接运行

```powershell
node apps\cli\bin\gen2vec.mjs <command> [options]
```

## 3. 命令参考

### 通用选项

| 选项 | 简写 | 说明 |
| --- | :---: | --- |
| `--help` | `-h` | 显示帮助 |
| `--wait <秒>` | | 等待后端就绪的最大秒数（默认 0，不等待） |

### `pipeline` — 完整流水线（文本 → 位图 → SVG）

最常用的命令，一条指令走完全流程。

```powershell
gen2vec_cli.exe pipeline --text "七里香" --prompt "清新国风、墨绿色金边"
gen2vec_cli.exe pipeline --text "Hello" --prompt "neon style" --vector-preset ultra
gen2vec_cli.exe pipeline --text "夏日冰饮 50%" --prompt "清爽蓝白配色" --seed 42
```

| 参数 | 简写 | 说明 | 必填 |
| --- | :---: | --- | :---: |
| `--text` | `-t` | 艺术字文本 | ✓ |
| `--prompt` | `-p` | 风格提示词 | |
| `--negative` | `-n` | 负面提示词 | |
| `--resolution` | `-r` | 分辨率（默认 `1024 x 1024`） | |
| `--seed` | `-s` | 随机种子 | |
| `--vector-preset` | | 矢量化预设 | |
| `--output-dir` | | 输出目录（默认 `./outputs`） | |
| `--output` | `-o` | 额外输出单个 SVG 路径 | |

### `generate` — 仅生成位图

```powershell
gen2vec_cli.exe generate --text "你好" --prompt "霓虹风格"
```

参数与 `pipeline` 相同，`--output` 输出单个 PNG 路径。

### `vectorize` — 仅矢量化

```powershell
gen2vec_cli.exe vectorize --input artwork.png --preset detailed
gen2vec_cli.exe vectorize -i input.png --preset ultra --preview
```

| 参数 | 简写 | 说明 | 必填 |
| --- | :---: | --- | :---: |
| `--input` | `-i` | 输入图片路径 | ✓ |
| `--preset` | | 矢量化预设 | |
| `--preview` | | 同时保存预览 PNG | |
| `--output-dir` | | 输出目录 | |
| `--output` | `-o` | 额外输出单个 SVG | |

### `batch` — 批量流水线

输入支持 TXT / CSV / JSON，每行一条：

```text
文本 | 风格提示词 | 负面提示词 | seed | resolution
```

```powershell
gen2vec_cli.exe batch --input-file tests\acceptance.txt --output-dir .\outputs\cli-batch
gen2vec_cli.exe batch --text "七里香|清新国风" --seed 20260605 --seed-step 1
gen2vec_cli.exe batch --input-file batch.csv --no-vectorize
```

| 参数 | 说明 | 必填 |
| --- | --- | :---: |
| `--input-file` | 批量输入文件（TXT / CSV / JSON） | 二选一 |
| `--text` | 直接传入一行或多行批量输入 | 二选一 |
| `--negative` | 全局负面提示词 | |
| `--resolution` | 全局分辨率 | |
| `--seed` | 全局随机种子 | |
| `--seed-step` | 每条 seed 递增步长 | |
| `--vector-preset` | 矢量化预设 | |
| `--no-vectorize` | 只生成 `original.png`，不做矢量化 | |
| `--output-dir` | 输出目录 | |

### `env` — 环境信息

显示 CLI 版本、后端 URL、health 状态、Node.js 运行时与输出目录配置。

```powershell
gen2vec_cli.exe env
```

### `health` — 后端健康检查

```powershell
gen2vec_cli.exe health
# txt2img 服务:    正常
# 矢量化服务:      正常
```

### `shutdown` — 关闭后端

```powershell
gen2vec_cli.exe shutdown
```

## 4. 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TXT2IMG_BACKEND_URL` | `http://127.0.0.1:9001/api/v1/txt2img` | 文生图服务地址 |
| `VECTORIZER_BACKEND_URL` | `http://127.0.0.1:8000/api/v1/vectorize` | 矢量化服务地址 |
| `TXT2IMG_WORKFLOW` | 空（使用后端降级链） | ComfyUI 工作流名称 |
| `ART_TEXT_OUTPUT_ROOT` | `./outputs` | 产物输出根目录 |

## 5. 矢量化预设

| 预设 | 颜色精度 | 斑点过滤 | 拐角阈值 | 长度阈值 | 图层差异 | 缩放 |
| --- | :---: | :---: | :---: | :---: | :---: | :---: |
| `clean` | 4 | 24 | 90 | 16 | 28 | 1 |
| `balanced` | 6 | 10 | 60 | 8 | 16 | 2 |
| `detailed` | 7 | 4 | 45 | 5 | 12 | 2 |
| `ultra` | 8 | 2 | 30 | 3 | 8 | 2 |

## 6. 输出结构

CLI 与桌面端使用相同的产物目录结构：

```text
outputs/
├─ task_YYYYMMDD_HHMMSS_mmm_<拼音slug>_seed-<seed>/
│  ├─ original.png
│  ├─ transparent.png
│  ├─ result.svg
│  ├─ preview.png
│  ├─ metadata.json
│  ├─ run.log
│  └─ workflows/
│     ├─ workflow_api.json
│     ├─ nodes.md
│     └─ model_dependencies.json
└─ batch_summary.csv
```

## 附：常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| CLI 报后端不可用 | 后端服务未启动 | 先启动桌面端，或用 `--wait 30` 等待 |
| 生成结果是纯色占位图 | ComfyUI 引擎或模型未安装 | 重启桌面端，在引导流程中选择下载 |
| 找不到输出文件 | 输出目录为安装目录下的 `outputs/` | 用 `gen2vec_cli.exe env` 查看实际输出目录 |
| SVG 打开后是位图 | 使用了 `--no-vectorize`，或只生成了位图 | 去掉 `--no-vectorize`，或对已有 PNG 执行 `vectorize` |
