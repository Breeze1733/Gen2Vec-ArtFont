# 参数配置说明

本文档汇总系统的全部可配置项：环境变量、矢量化参数、接口请求字段与输出目录规则。

> **参数取值以源码为准**：
> - 矢量化预设 → `services/vectorizer-api/app/vectorization.py` 的 `PRESET_CONFIG`
> - 接口字段与约束 → `services/*/app/models.py`
> - 环境变量 → `services/*/app/main.py`、`apps/desktop/electron/main.cjs`

---

## 一、环境变量

| 变量 | 默认值 | 作用范围 | 说明 |
| --- | --- | --- | --- |
| `ART_TEXT_OUTPUT_ROOT` | 见「六、输出目录规则」 | 桌面端 / CLI | 产物输出根目录，设置后覆盖默认规则 |
| `TXT2IMG_BACKEND_URL` | `http://127.0.0.1:9001/api/v1/txt2img` | 桌面端 / CLI | 文生图接口完整 URL |
| `VECTORIZER_BACKEND_URL` | `http://127.0.0.1:8000/api/v1/vectorize` | 桌面端 / CLI | 矢量化接口完整 URL |
| `TXT2IMG_WORKFLOW` | 空 | CLI | 指定 ComfyUI 工作流名；为空时使用后端降级链 |
| `AUTO_START_COMFYUI` | `1` | txt2img-api | 是否在启动时自动拉起 ComfyUI |
| `COMFYUI_HOST` | `http://127.0.0.1:8188` | txt2img-api | ComfyUI API 地址 |
| `COMFYUI_POLL_TIMEOUT` | `900` | txt2img-api | 轮询 ComfyUI 完成的最大秒数 |
| `COMFYUI_POLL_INTERVAL` | `1.0` | txt2img-api | 轮询间隔秒数 |
| `WORKFLOW_PATH` | 空 | txt2img-api | 指定 ComfyUI API 格式 JSON 的绝对路径，**优先级高于请求中的 `workflow`** |
| `COMFYUI_LAUNCHER_BAT` | 空 | txt2img-api | 使用自定义 ComfyUI 启动脚本 |
| `COMFYUI_NETWORK_MODE` | `offline` | txt2img-api | 写入 ComfyUI-Manager 配置，减少启动时的联网检查 |
| `COMFYUI_ENGINE_URLS` | 空 | 引擎下载脚本 | 自定义 ComfyUI 引擎下载地址，多个用 `;` 或 `,` 分隔 |

工作流选择优先级：

```
WORKFLOW_PATH  >  请求中的 workflow  >  按文本内容自动路由
```

## 二、矢量化参数

### 2.1 预设

四个预设对应不同的细节保留与文件体积权衡。选择预设后仍可单独覆盖下方六个底层参数。

| 预设 | 名称 | 适用场景 |
| --- | --- | --- |
| `clean` | 清爽 | 色块分明、结构简单的图，输出体积最小 |
| `balanced` | 平衡 | **默认值**，兼顾质量与体积 |
| `detailed` | 精细 | 细节丰富、需要保留较多层次 |
| `ultra` | 超清 | 追求最高还原度，输出体积最大 |

各预设的底层参数值：

| 预设 | `color_precision` | `filter_speckle` | `corner_threshold` | `length_threshold` | `layer_difference` | `scale` |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `clean` | 4 | 24 | 90 | 16 | 28 | 1 |
| `balanced` | 6 | 10 | 60 | 8 | 16 | 2 |
| `detailed` | 7 | 4 | 45 | 5 | 12 | 2 |
| `ultra` | 8 | 2 | 30 | 3 | 8 | 2 |

> 上表取自 `vectorization.py` 的 `PRESET_CONFIG`，与桌面端 `App.vue` 的 `vectorPresets`、`apps/cli/README.md` 的预设表一致。

### 2.2 底层参数

桌面端输入框与接口校验使用同一组范围：

| 参数 | 范围 | 作用 |
| --- | :---: | --- |
| `color_precision` 颜色精度 | 1–8 | CIELAB K-Means 的聚类数 $k$，值越高保留的颜色层次越多 |
| `filter_speckle` 斑点过滤 | 0–64 | 面积过滤阈值，值越高去除的小色块越多 |
| `corner_threshold` 拐角阈值 | 1–180 | 硬角判定阈值，值越低越容易保留尖角 |
| `length_threshold` 长度阈值 | 1–64 | 参与路径拟合的最小线段长度，值越低细节越多 |
| `layer_difference` 图层差异 | 1–64 | 图层间的颜色差异阈值 |
| `scale` 放大倍数 | 1–4 | 矢量化前的放大倍数，提升边缘平滑度 |

> 范围取自 `services/vectorizer-api/app/models.py` 的 `VectorConfig`，
> 桌面端 `apps/desktop/src/renderer/components/VectorParams.vue` 的输入框约束与之保持一致。

> `color_precision` 的上限为 8，由接口校验、桌面端输入框与引擎钳位三处共同保证一致
> （`models.py` 的 `le=8`、`VectorParams.vue` 的 `max="8"`、`vectorization.py` 的 `min(8, cp)`）。

### 2.3 其余开关

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | :---: | --- |
| `evaluate_quality` | bool | `true` | 是否计算回渲染保真度得分（关闭可节省时间） |
| `remove_edge_white_background` | bool | `true` | 是否滤除与画布边缘连通的纯白底衬 |
| `white_value_threshold` | int 200–255 | `245` | 近纯白判定的明度阈值 $V_{\text{thresh}}$ |
| `white_saturation_threshold` | int 0–80 | `20` | 近纯白判定的饱和度阈值 $S_{\text{thresh}}$ |

### 2.4 预设派生的内部参数

除上述显式参数外，每个预设还派生一组追踪前处理参数（定义于 `TRACE_CLEANUP_CONFIG`）：

| 预设 | `alpha_floor` | `min_area_divisor` | `morph` | `median` | `solid_alpha` | `smooth_mask` | `snap_near_white` |
| --- | ---: | ---: | :---: | :---: | :---: | :---: | :---: |
| `clean` | 48 | 1500 | 0 | ✓ | ✓ | ✓ | — |
| `balanced` | 24 | 3600 | 0 | — | — | — | — |
| `detailed` | 10 | 12000 | 0 | — | — | — | — |
| `ultra` | 4 | 24000 | 0 | — | — | — | — |

- `alpha_floor`：Alpha 二值化的下限，值越高前景越收紧
- `min_area_divisor`：连通域面积阈值 $S_{\min} = \max(2, W \times H / D_{\min})$ 的分母，值越大保留的细节越多

## 三、文生图接口参数

`POST /api/v1/txt2img`，请求体字段：

| 字段 | 类型 | 默认 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `text` | string | `""` | ≤ 60 | 要渲染的文字内容；允许为空（仅生成背景与风格） |
| `prompt` | string | `""` | ≤ 600 | 风格描述 |
| `negative_prompt` | string | `""` | ≤ 600 | 负面提示词 |
| `resolution` | string | `1024 x 1024` | ≤ 32 | 分辨率，格式 `宽x高` |
| `seed` | int | `0` | — | 随机种子，固定可复现 |
| `style` | string | `default` | ≤ 40 | **保留字段**，仅记录到元数据，不影响生成 |
| `format` | enum | `PNG` | `PNG` / `PNG + SVG` | 输出格式 |
| `workflow` | string | `""` | ≤ 64 | 工作流文件名（不含路径与扩展名），如 `flux_schnell`；为空时按内容路由 |

输入规范化规则：

- `text`：strip 并把内部连续空白折叠为单个空格
- `prompt` / `negative_prompt` / `style`：strip
- `resolution`：转小写、去空格，校验为 `宽x高` 且均为正整数

## 四、矢量化接口参数

`POST /api/v1/vectorize`，请求体字段：

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `source_type` | enum | `upload` | `upload`（用户上传位图）/ `generated`（流水线产出的位图） |
| `text` | string | `""` | 文字内容，写入元数据 |
| `prompt` | string | `""` | 风格描述，写入元数据 |
| `negative` | string | `""` | 负面提示词，写入元数据 |
| `resolution` | string | `1024 x 1024` | 分辨率 |
| `format` | string | `PNG + SVG` | 输出格式 |
| `seed` | int / null | `null` | 随机种子 |
| `vector` | object | 见下 | 矢量化参数（`VectorConfig`） |
| `image_base64` | string / null | `null` | 上传图片的 base64 |
| `image_path` | string / null | `null` | 上传图片的路径 |
| `image_name` | string / null | `null` | 原文件名，用于命名任务目录 |
| `generated_image` | object / null | `null` | 流水线传递的图片引用（`artifact_id` / `image_base64` / `file_path`） |

`vector` 对象即「二、矢量化参数」中的全部字段。

响应字段：

| 字段 | 说明 |
| --- | --- |
| `transparent_png` | 透明背景 PNG（data URL） |
| `preview_png` | SVG 回渲染预览 PNG（data URL） |
| `png` | 兼容旧调用方的别名，与 `preview_png` 相同（SVG 回渲染预览图） |
| `svg` | SVG 矢量图文本 |
| `metadata` | 结构化元数据 |

## 五、工作流降级链

未显式指定 `workflow` 时，`txt2img-api` 按文本内容选择候选工作流，逐级降级：

| 文本类型 | 优先级 1 | 优先级 2 | 兜底 |
| --- | --- | --- | --- |
| 纯中文 | `qwen_image_2512_gguf` | `test_z_image_turbo` | Pillow stub |
| 纯英文 | `flux_schnell` | `test_z_image_turbo` | Pillow stub |
| 中英混排 | `test_z_image_turbo` | — | Pillow stub |

语种判定只统计汉字与拉丁字母，数字、标点、符号、空白不参与，因此 `冰川 100%` 归为纯中文。

全部候选失败时降级为内置 Pillow 占位引擎——此时会生成纯色占位图，并在元数据中标记 `engine=local-studio`、`fallback_tier=-1`，可用于自动化验收判断是否真正跑通了 ComfyUI。

## 六、输出目录规则

| 运行方式 | 输出根目录 |
| --- | --- |
| CLI | 当前工作目录下的 `outputs/` |
| 桌面端（开发模式） | 仓库根目录的 `outputs/` |
| 桌面端（打包模式） | **安装目录下的 `outputs/`**（与 `gen2vec_cli.exe` 同级） |
| 任意方式 | 设置 `ART_TEXT_OUTPUT_ROOT` 后使用该目录 |

> 当前实现见 `apps/desktop/electron/main.cjs` 的 `getOutputRoot()`。

每次任务生成独立目录，命名格式：

```
task_<时间戳>_<文本转写>_seed-<种子>
```

批量模式额外生成 `batch_summary.csv` 汇总表。

## 七、构建期参数

构建脚本支持 `-Toolchain` 参数选择依赖管理方式：

```powershell
# 两个后端各自构建（默认自动检测：有 uv 用 uv，否则用 python）
.\services\txt2img-api\scripts\build-backend-exe.ps1
.\services\vectorizer-api\scripts\build-backend-exe.ps1

# 强制指定依赖管理方式（两个脚本参数相同，以下以 txt2img-api 为例）
.\services\txt2img-api\scripts\build-backend-exe.ps1 -Toolchain uv
.\services\txt2img-api\scripts\build-backend-exe.ps1 -Toolchain python
```

`.\scripts\quick-packaging.ps1` 会依次调用上述两个构建脚本，并继续构建 CLI 与桌面端安装包。

打包输出目录由 `apps/desktop/package.json` 的 `build.directories.output` 决定，当前为仓库根目录的 `release/`。
