# 安装部署说明

本文档面向**部署人员与评审人员**，说明如何在本地部署「矢量艺术字生成器」并复现生成结果。

系统提供两条部署路径：

| 路径 | 适用场景 | 前置要求 |
| --- | --- | --- |
| **A. 交付包部署** | 评审复现、非开发人员使用 | Windows 10 / 11 |
| **B. 源码部署** | 需要修改代码、二次开发 | Python 3.13+、Node.js 20+ |

---

## 一、环境要求

### 硬件

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（x64） |
| 显存 | 12 GB 及以上，推荐 NVIDIA 独显 |
| 内存 | 32 GB 推荐 |
| 磁盘 | 路径 A 需 ≥ 80 GB 可用空间；路径 B 另需 ComfyUI 引擎与模型空间 |

无 GPU 时系统仍可运行：矢量化模块正常工作，文生图会提示不可用并降级。

### 软件

| 组件 | 版本 | 用途 |
| --- | --- | --- |
| Python | 3.13+ | 两个后端服务（路径 B） |
| Node.js | 20+ | 桌面端与 CLI（路径 B） |
| uv | 推荐 | 两个后端的依赖管理；未安装时可用 pip 代替 |
| ComfyUI | 便携版 | 由脚本自动获取，无需手工安装 |

---

## 二、路径 A：交付包部署

### 1. 安装

双击安装包 `矢量艺术字生成器 Setup 1.0.1.exe`。

安装向导为非一键式，可选择「仅为我安装」或「为所有用户安装」，并可自选安装目录。默认路径：

- 仅为我安装：`%LOCALAPPDATA%\Programs\矢量艺术字生成器`
- 为所有用户安装：`C:\Program Files\矢量艺术字生成器`

安装包内已内置以下内容，无需另外准备：

- 桌面端主程序
- 两个后端 EXE（`txt2img-backend.exe`、`vectorizer-backend.exe`）
- 矢量化模型（`models/rembg/isnet-general-use.onnx`）
- CLI 自动化验收控制台（`gen2vec_cli.exe`）
- 验收脚本与测试样例（`tests/`）

### 2. 首次启动

首次启动会进入引导流程，共 4 步：

| 步骤 | 内容 |
| --- | --- |
| 1 | 检查推理引擎 ComfyUI；缺失时弹窗询问「跳过 / 开始下载」 |
| 2 | 检查 AI 模型；缺失时弹窗询问「跳过 / 开始下载」 |
| 3 | 启动两个后端服务（矢量化 `8000`、文生图 `9001`） |
| 4 | 进入主界面 |

矢量化所需的 rembg ONNX 模型已随安装包内置，无需下载。首次启动需要额外获取的是**文生图**所需的 ComfyUI 引擎与 AI 模型（安装包为控制体积未内置）：

| 内容 | 体积 |
| --- | --- |
| ComfyUI 便携版引擎 | 压缩包约 1.8 GB，解压后数 GB |
| 文生图模型与权重（11 个文件） | 合计约 58 GB |

模型清单：

| 子目录 | 文件 | 体积 |
| --- | --- | --- |
| `diffusion_models` | `z_image_turbo_bf16.safetensors` | 12.3 GB |
| `diffusion_models` | `flux1-schnell-fp8-e4m3fn.safetensors` | 11.9 GB |
| `text_encoders` | `qwen_2.5_vl_7b_fp8_scaled.safetensors` | 9.4 GB |
| `diffusion_models` | `qwen-image-2512-Q3_K_M.gguf` | ~9 GB |
| `text_encoders` | `qwen_3_4b.safetensors` | 8.0 GB |
| `text_encoders` | `t5xxl_fp8_e4m3fn.safetensors` | 4.9 GB |
| `loras` | `Qwen-Image-Lightning-4steps-V1.0.safetensors` | 1.7 GB |
| `vae` | `ae.safetensors` | 335 MB |
| `vae` | `qwen_image_vae.safetensors` | 254 MB |
| `text_encoders` | `clip_l.safetensors` | 246 MB |
| `inspyrenet/.transparent-background` | `ckpt_base.pth` | 170 MB |

下载脚本支持镜像回退，网络受限时可用环境变量 `COMFYUI_ENGINE_URLS` 指定自定义地址。

**跳过下载的后果**：文生图会降级为内置的 Pillow 占位引擎（不产生真实艺术字），但**矢量化模块仍可正常使用**，可以直接矢量化桌面端已有的 PNG / JPG 图片。

### 3. 验证安装

先启动桌面端并等待两个后端就绪，然后在安装目录下打开终端（若安装时改过目录，请替换为实际路径）：

```powershell
cd "$env:LOCALAPPDATA\Programs\矢量艺术字生成器"
.\gen2vec_cli.exe health
```

预期输出两个服务均正常：

```text
txt2img 服务:    正常
矢量化服务:      正常
```

查看完整环境信息：

```powershell
.\gen2vec_cli.exe env
```

## 三、路径 B：源码部署

### 1. 获取代码与依赖

```powershell
git clone https://github.com/Breeze1733/Gen2Vec-ArtFont-App.git
cd Gen2Vec-ArtFont-App
```

安装两个后端的 Python 依赖（推荐 uv，各自建独立 `.venv`）：

```powershell
cd services\vectorizer-api
uv sync

cd ..\txt2img-api
uv sync
```

未安装 uv 时改用 pip：

```powershell
cd services\vectorizer-api
pip install -r requirements.txt

cd ..\txt2img-api
pip install -r requirements.txt
```

安装桌面端依赖：

```powershell
cd apps\desktop
npm install
```

### 2. 获取 ComfyUI 引擎与模型

```powershell
.\scripts\setup-deps.ps1
```

该脚本依次执行四步，每步会询问确认（按 `n` 可跳过）：

| 步骤 | 内容 |
| --- | --- |
| 1 | 下载 ComfyUI 便携版引擎，并安装 `ComfyUI-GGUF`、`ComfyUI-Inspyrenet-Rembg` 两个自定义节点 |
| 2 | 配置 ComfyUI（应用补丁、安装所需 Python 包） |
| 3 | 下载文生图 AI 模型到 ComfyUI 的 `models/` |
| 4 | 下载矢量化 rembg ONNX 模型 |

### 3. 启动

需要三个终端。

矢量化后端（端口 8000）：

```powershell
cd services\vectorizer-api
uv run vectorizer-api
```

文生图后端（端口 9001）：

```powershell
cd services\txt2img-api
uv run txt2img-api
```

如需禁止文生图服务自动拉起 ComfyUI：

```powershell
$env:AUTO_START_COMFYUI = "0"
uv run txt2img-api
```

桌面端：

```powershell
cd apps\desktop
npm run electron:dev
```

开发模式下 Electron 不托管后端进程，需保持上述两个终端运行。

### 4. 验证安装

```powershell
node apps\cli\bin\gen2vec.mjs health
node apps\cli\bin\gen2vec.mjs env
```

### 5. 构建交付包

如需从源码构建完整交付物：

```powershell
.\scripts\quick-packaging.ps1
```

该脚本依次构建两个后端 EXE、CLI EXE 与桌面端安装包，产物输出到仓库根目录 `release/`。

## 四、如何验收

### 手工验收

按赛题验收项逐条核对：

| # | 验收项 | 操作 | 合格标准 |
| --- | --- | --- | --- |
| 1 | 功能完整性 | 依次执行单条生成、批量生成、图片矢量化 | 三种模式均可用，输出完整 |
| 2 | 提示词生成能力 | 用 `tests/fixtures/` 中的样例提示词生成 | 文字内容基本正确、主体完整、风格匹配 |
| 3 | 透明 PNG 输出 | 检查任务目录下 `transparent.png` | 背景透明，边缘无明显白边 / 黑边或残留噪声，主体未裁切 |
| 4 | 矢量化质量 | 用矢量软件打开 `result.svg` | 不嵌入位图作为主体，路径闭合可编辑；对比 `preview.png` 与 `transparent.png`，主体轮廓一致 |
| 5 | 批量处理能力 | 批量模式输入不少于 100 条提示词 | 结果、日志与元数据完整，`batch_summary.csv` 齐全 |
| 6 | 处理性能 | 计时单图矢量化与完整流水线 | 单图矢量化 ≤ 10 秒；单条提示词生成至矢量化完成 ≤ 90 秒 |
| 7 | 兼容性 | 在 Windows 10 / 11 上部署运行 | 安装、启动、导出均正常；SVG 可被 Inkscape / Illustrator 打开 |
| 8 | 交付物完整性 | 对照交付清单核对 | 源码、依赖说明、工作流 JSON、部署说明、测试样例、演示材料齐全 |

手工验收用到的样例提示词位于 `tests/fixtures/`，覆盖国风品牌、海报促销、节日活动、英文标题、混合文本五类。

### 自动化验收

测试集与验收脚本位于 `tests/`：`acceptance.txt` 提供 120 条正文用例和 3 条 `#route` 路由用例，脚本会规范化输入、调用 `gen2vec_cli.exe batch` 并核验产物。

前置条件：两个后端已启动（启动桌面端即可）。在仓库根目录或安装目录执行：

```powershell
.\tests\run-acceptance.ps1
```

也可以直接双击 `tests\run-acceptance.bat`。脚本会自动在安装目录、仓库根目录和 `apps\cli\dist\` 中查找 `gen2vec_cli.exe`；如需指定：

```powershell
.\tests\run-acceptance.ps1 -CliPath "$env:LOCALAPPDATA\Programs\矢量艺术字生成器\gen2vec_cli.exe"
```

常用参数：

| 参数 | 作用 |
| --- | --- |
| `-DryRun` | 只打印场景计划，不调用后端 |
| `-Full` | 运行包含 `#route` 用例的完整套件 |
| `-VerifyOnly <csv>` | 只核验已有的 `batch_summary.csv` |
| `-NoVectorize` | 跳过矢量化，只验证位图、元数据与日志 |
| `-MaxE2eMs <毫秒>` | 设置单条端到端耗时上限 |
| `-MaxVectorMs <毫秒>` | 设置单条矢量化耗时上限 |

脚本会检查批量汇总表与输入是否一致、每个任务目录的 7 类产物是否齐全、PNG 是否可读、SVG 是否为可编辑矢量、`metadata.json` 是否合法，以及 `run.log` 是否包含状态与耗时字段。耗时默认只记录，只有传入 `-MaxE2eMs` / `-MaxVectorMs` 时才作为失败条件。

## 五、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 文生图输出为纯色占位图 | ComfyUI 引擎或模型未安装，降级到 Pillow 引擎 | 重新启动应用，在引导流程中选择下载 |
| 提示显存不足 | 显存低于 12 GB 或已被其他程序占用 | 关闭占用显存的程序；或仅使用矢量化模式 |
| 提示端口 8000 / 9001 被占用 | 已有其他进程占用端口 | 关闭占用进程后重启应用 |
| 找不到输出文件 | 输出根目录为**安装目录下的 `outputs/`** | 在结果面板点击「打开输出目录」，或查看安装目录下的 `outputs/` |
