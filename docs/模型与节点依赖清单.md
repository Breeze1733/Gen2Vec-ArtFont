| 分发包 | `ComfyUI_windows_portable_nvidia.7z` |
| 来源 | [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI) releases（latest） |

本项目的自有代码（两个后端服务、桌面端、CLI）均独立分发。

## 七、获取方式

### 一键获取（推荐）

```powershell
.\scripts\setup-deps.ps1
```

依次执行四步，每步询问确认：

| 步骤 | 内容 |
| --- | --- |
| 1 | 下载 ComfyUI 引擎 + 安装 2 个自定义节点 |
| 2 | 配置 ComfyUI（应用补丁、安装 Python 包） |
| 3 | 下载 11 个 AI 模型 |
| 4 | 下载矢量化 rembg ONNX 模型 |

### 单独获取

```powershell
.\scripts\download-comfyui-engine.ps1    # 引擎 + 自定义节点
.\scripts\configure-comfyui.ps1           # 引擎配置
.\scripts\download-models.ps1             # 11 个 AI 模型
.\services\vectorizer-api\models\rembg\download-isnet-general-use.ps1   # ONNX 模型
```

### 镜像与自定义地址

| 场景 | 方式 |
| --- | --- |
| HuggingFace 直连不通 | 脚本默认走 `hf-mirror.com`；加 `-NoMirror` 强制直连 |
| 自定义引擎地址 | 设置环境变量 `COMFYUI_ENGINE_URLS`（多个用 `;` 或 `,` 分隔） |
| 自定义节点镜像 | 脚本内置 `gh-proxy.com`、`gh.llkk.cc`、`ghproxy.net`、`ghfast.top`、`hub.gitmirror.com` 依次回退 |

### 交付包部署（无需下载）

安装包内**已内置矢量化 ONNX 模型**；首次启动时引导流程会询问是否下载 ComfyUI 引擎与文生图模型。
跳过下载不影响矢量化功能，仅文生图降级为内置 Pillow 占位引擎。
